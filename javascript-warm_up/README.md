# Introduction to JavaScript

## Description

This project is an introduction to **JavaScript**, a programming language commonly used to make websites interactive and dynamic.

The exercises in this project focus on learning the fundamentals of JavaScript, including variables, constants, data types, operators, functions, loops, conditionals, and basic scripting.

The scripts are executed using **Node.js** from the command line.

## Learning Objectives

By completing this project, I will learn how to:

- Create and use variables and constants
- Print output using `console.log()`
- Work with different JavaScript data types
- Use operators and expressions
- Write conditional statements
- Create and use functions
- Work with loops
- Understand the difference between `var`, `let`, and `const`
- Follow JavaScript coding standards
- Execute JavaScript files using Node.js

## Requirements

- Node.js
- JavaScript
- Ubuntu/Linux terminal or another Unix-like environment
- Semistandard for code-style checking

## Running the Scripts

JavaScript files can be executed using Node.js:

```bash
node filename.js
```

For executable scripts, the file can also be run directly:

```bash
./filename.js
```

Make sure the file has execute permissions:

```bash
chmod +x filename.js
```

## Code Style

This project follows the **JavaScript Standard Style**.

Code can be checked using:

```bash
semistandard filename.js
```

If there are no errors, the command will produce no output.

## Example

A simple JavaScript program:

```javascript
#!/usr/bin/node

const myVar = "JavaScript is amazing";

console.log(myVar);
```

Running the script:

```bash
./0-javascript_is_amazing.js
```

Output:

JavaScript is amazing
